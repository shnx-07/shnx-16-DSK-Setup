# SHNX Shell Fonts

This directory hosts bundled font files (e.g. TTF/OTF Nerd Fonts) for `shnx-shell`.

Project font families are centrally managed and configured in:
`theme/Typography.qml`

## Default Font Configuration
- **Primary Font**: `JetBrainsMono Nerd Font`
- **Icon Font**: `Symbols Nerd Font`
